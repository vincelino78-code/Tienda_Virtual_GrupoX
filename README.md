# Tienda Virtual en Consola

Este es mi proyecto de una tienda virtual que funciona directamente en la terminal de comandos, programado en Python utilizando Programación Orientada a Objetos (POO).

## Estructura del Proyecto
- `main.py`: Menú interactivo del sistema.
- `clases/`: Carpeta que contiene la lógica de los objetos.
  - `producto.py`: Contiene los datos del producto con encapsulamiento.
  - `carrito.py`: Maneja la lista de compras.
  - `usuario.py`: Administra los usuarios usando herencia.

## Historias de Usuario (User Stories)

1. **Como Cliente**, quiero ver la lista de productos con su precio y stock disponible para saber qué puedo comprar.
2. **Como Cliente**, quiero agregar productos a un carrito de compras para guardar lo que me interesa llevar.
3. **Como Cliente**, quiero revisar el contenido de mi carrito para confirmar mis productos elegidos antes de pagar.
4. **Como Administrador**, quiero poder modificar el precio y el stock de los productos para mantener la tienda actualizada.
